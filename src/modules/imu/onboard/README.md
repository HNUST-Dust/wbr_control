# 板载 IMU 姿态估计

该目录只服务于后续板载 ICM42688P 链路，不参与 HI91 外置 IMU 的数据处理。

预期数据流：

1. SPI 驱动读取 ICM42688P 原始寄存器值。
2. 驱动完成坐标轴映射和量程换算，输出角速度 `rad/s`、加速度 `m/s²` 和温度。
3. IMU 模块在固定周期运行；静止启动阶段用一段样本估计陀螺仪零偏。
4. 去除零偏后的同一份六轴数据分别输入 `QuaternionEkf` 和
   `MahonyAttitudeEstimator`。二者是并行估计器，不互相串联。
5. 最终使用哪一路姿态由板载 IMU 模块决定，算法文件不直接读取 SPI 或发布消息。

`QuaternionEkf` 的稳定状态判断依赖加速度模长约为 `9.8 m/s²`，因此不能直接传入
以 `g` 为单位的数据。Mahony 只使用加速度方向，但仍统一采用相同的 SI 单位接口。

HI91 已在传感器内部完成姿态解算；`hi91_imu_module` 继续原样发布协议中给出的欧拉角、
四元数、角速度和加速度，不经过这里的 Mahony 或 EKF。

## ICM42688P 接入后的 Eigen 重构

`QuaternionEkf` 已使用 Eigen 固定尺寸矩阵。当前 Mahony 暂时保留经过实机项目验证的
标量展开实现；正式接入 ICM42688P 并跑通板载姿态链路后，再将其向量和四元数运算重构为
`Eigen::Vector3f` 与 `Eigen::Quaternionf`。

重构前应先录制一组可重复回放的 ICM42688P 原始六轴数据，至少覆盖：

- 静止与启动零偏校准；
- 绕 X、Y、Z 轴分别旋转；
- 连续多轴运动；
- 长时间静止与振动工况。

以当前标量 Mahony 输出作为基准，Eigen 版本需要确认：

1. 四元数统一采用接口顺序 `(w, x, y, z)`，不要误用 Eigen `coeffs()` 的
   `(x, y, z, w)` 存储顺序。
2. 明确四元数表示方向、角速度乘法方向、重力方向和叉乘顺序。
3. 相同输入下四元数、欧拉角和积分反馈与基准输出一致，允许误差应在测试中明确。
4. 通过录制数据回放、长时间漂移测试和实机姿态方向检查后，才替换标量实现。

这次重构只改变 Mahony 的内部数学表达，不将其抽取为通用算法库，也不改变 HI91 数据链路。
