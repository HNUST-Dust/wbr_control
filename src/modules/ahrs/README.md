# 板载 IMU 姿态估计

该目录只服务于后续板载 ICM42688P 链路，不参与 HI91 外置 IMU 的数据处理。

预期数据流：

1. SPI 驱动读取 ICM42688P 原始寄存器值。
2. 驱动只完成量程换算，输出 IMU 原始坐标系下的角速度 `rad/s`、加速度 `m/s²` 和温度。
3. IMU 模块在固定周期运行；静止启动阶段用一段样本估计陀螺仪零偏。
4. 去除零偏后的六轴数据输入 `QuaternionEkf`。
5. EKF 始终在底盘 IMU 原始坐标系中运行。
6. AHRS 只发布底盘 IMU 坐标系下的欧拉角、EKF 零偏修正角速度和时间戳；
   不发布诊断、调试或 oscilloscope telemetry。
7. 底盘线程读取该快照后，通过通用 `TfTree` 转换到底盘坐标系再进入闭环。

底盘 IMU 分支不会连接 `pc_link` 坐标系；未来云台 IMU 使用独立的
`gimbal_imu -> gimbal -> pc_link` 分支，其输出四元数供视觉上位机协议使用。
坐标变换属于消费模块职责。姿态不能按欧拉角分量直接改符号。
设 `A=R_target_from_imu`，滤波后的姿态使用
`R_target=A*R_imu*A.transpose()` 做坐标约定变换，角速度使用
`omega_target=A*omega_imu`。因此单位姿态变换后仍为单位姿态，不会引入固定的 180° yaw。

`QuaternionEkf` 的稳定状态判断依赖加速度模长约为 `9.8 m/s²`，因此不能直接传入
以 `g` 为单位的数据。

当前 1 kHz 估计链路借鉴了旧 BMI088 实机方案：启动时连续静止采集 1000 帧估计陀螺仪
零偏，EKF 使用 `Q1=10`、`Q2=0.001`、`R=1e7`、`lambda=1` 的参数和旧版初始
协方差，并保留严格创新门控及“加速度不直接修正 yaw”的处理。新实现额外要求角速度小于
`0.3 rad/s` 且加速度模长处于 `1g ± 0.5 m/s²` 才启用 EKF 重力观测，运动或冲击时
只做陀螺仪预测。旧工程的 Z 轴 `0.003 rad/s` 强制死区没有迁移，以免吞掉真实的慢速
转动；温控也未迁移，因为当前板卡尚未提供已确认的 IMU 加热 PWM 硬件接口。

AHRS 周期线程不等待 DRDY、SPI 或信号量：每个 1 ms 周期只轮询上一次异步传输结果、
尝试发起下一次传输并处理已完成帧。传感器初始化阶段允许短延时，但发生在线程启动前，
不进入 1 kHz 实时循环。

HI91 已在传感器内部完成姿态解算；`hi91_imu_module` 继续原样发布协议中给出的欧拉角、
四元数、角速度和加速度，不经过这里的 EKF。

`QuaternionEkf` 使用 Eigen 固定尺寸矩阵，四元数接口顺序为 `(w, x, y, z)`。
